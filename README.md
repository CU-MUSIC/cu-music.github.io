## 文件夹

| 位置 | 放什么 |
|---|---|
| `pics/` | CU MUSIC 主页的图片 |
| `chefdao/assets/` | ChefDao 的 logo、图标、分享卡片图 |
| `chefdao/about/` | ChefDao 主页的个人照片 |
| `albums.js` | 作品列表数据（两个主页共用） |
| `api/` | Notion 接口（GitHub Pages 不运行它） |

## 不会上传的（只在本机）

- `_backups/`：旧版本备份
- `tools/`：浏览器脚本等小工具
- `*.bak*`、`_internal-*`：临时备份、内部定价文档和海报
